# Archive

Files kept for reference. Nothing here is used by the current Movens build.

## [`moveo`](moveo)

Original files from the [BCN3D Moveo](https://github.com/BCN3D/BCN3D-Moveo), which Movens is forked from.

| Path | Contents |
|---|---|
| [`cad`](moveo/cad) | SolidWorks parts and assemblies |
| [`firmware/Marlin_BCN3D_Moveo`](moveo/firmware/Marlin_BCN3D_Moveo) | Marlin firmware for Arduino Mega + RAMPS |
| [`bom`](moveo/bom) | Bill of materials |
| [`manual`](moveo/manual) | User and assembly manual |

The manual is still the best guide to printing and assembling the structural parts Movens shares with the Moveo.

## [`legacy`](legacy)

Earlier Movens iterations, superseded by the files in [`cad`](../cad). Not maintained.

| Path | Contents |
|---|---|

| [`parts.f3d`](legacy), [`1M3A.STEP`](legacy) | Loose parts from earlier work |
| [`uno box`](legacy/uno%20box) | Controller enclosure from an earlier Arduino Uno build |
| [`temp`](legacy/temp) | Scratch STLs |
